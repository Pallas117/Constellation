# Refined brand symbols (source copies)

Flat vector symbols from the Lightbound Design System artifact ("Symbols" group, refined 16–18 Oct 2026),
https://claude.ai/artifact/CvWgPQyJio2m5uHPyZZHdv. Copied unchanged; the Lightbound Brand Book (15 Oct, with
16 and 18 Oct updates) is the rule set:

- Lightbound "Black hole": the ray-traced silhouette, flat, 3-stop gradient, ring 7 units (no blur).
- Gauss Aurora "Radiation belts": two solid belts (outer lime, inner amber), one L 6.4 field line; reads at 16 px.
- Turnstone v6, refined 4 Nov (Josh: "more clean and professional"): the turnstone landing at the tide line, now
  exactly symmetric on one angle family, no hairline details. Minimum 32 px; below that use the badge.
- Constellation, refined 4 Nov: navy disc, gold ring broken by five evenly spaced stars, three gold key stars on an
  equilateral triangle with one white star off each. The 3-node icon is for 32 px and under.

The Constellation and Turnstone files are generated by `website/tools/make_marks.py` (run it, not a hand edit);
copy them back to the Design System so it stays the source for decks. Published marks are cached for a week, so
a changed mark gets a new published name (`-v2`).

`website/tools/make_lockups.py` builds the horizontal lockups from these; `build_assets.py` copies them into
`public/assets/marks/`. Do not hand-edit the symbols here: Lightbound and Gauss come from the Design System; Constellation and Turnstone
from make_marks.py.
